# Владимир Мачулин

Backend-разработчик на Go · Москва

Разрабатываю серверные приложения на Go: проектирую API, работаю с базами данных
и асинхронной обработкой сообщений. В проектах уделяю внимание конкурентному
доступу к данным и обработке ошибок. Решаю алгоритмические задачи на LeetCode.

### Стек

- **Язык и API:** Go · SQL · REST API · gRPC
- **Базы данных и брокеры:** PostgreSQL · Redis · Kafka
- **Инфраструктура:** Docker · Docker Compose · Kubernetes
- **Мониторинг, логирование и трассировка:** Prometheus · Grafana · Jaeger · Graylog
- **Инструменты:** Git · Postman
